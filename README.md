# Diabetes-Prediction
This project is a full-stack web application that predicts the likelihood of diabetes in individuals based on key medical parameters such as glucose level, BMI, age, and insulin. The frontend is developed using HTML, CSS, and JavaScript, providing a user-friendly form for input. The backend is built with Python Flask, which loads a trained Random Forest machine learning model saved as model.pkl. When a user submits their data, it is sent to the Flask API via a POST request, where the model processes it and returns a prediction (Positive/Negative for diabetes). The response is then displayed in real-time on the frontend. This project demonstrates the integration of machine learning models into web applications and showcases end-to-end deployment of data science solutions
